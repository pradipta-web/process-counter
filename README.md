# Python Process Counter

A lightweight Python application for monitoring running system processes in real time.

## Features

- Count total running processes.
- Display processes by status.
- Show process ID (PID).
- Display process names.
- Monitor CPU usage per process.
- Display the top 10 processes by CPU usage.
- Automatically refresh every 2 seconds.
- Handle inaccessible and terminated processes.

## Requirements

- Python 3.x
- psutil

## Installation

Clone this repository:

```bash
git clone https://github.com/pradipta-web/python-process-counter.git
```

Navigate to the project directory:

```bash
cd python-process-counter
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the application:

```bash
python app.py
```

Press `CTRL+C` to stop monitoring.
